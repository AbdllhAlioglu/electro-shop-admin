## 📋 Overview

Electro Shop Admin Panel is a modern, responsive administration interface designed to manage electronic products, orders, customers, and inventory. It provides real-time analytics, detailed reports, and a seamless user experience for e-commerce management.

> **Note**: Access to the admin panel requires authentication. For demo credentials, please [contact the developer](#contact).

## ✨ Features

- **Dashboard Analytics**: Real-time overview of key metrics and performance indicators
- **Product Management**: Add, edit, delete, and manage product inventory
- **Category Management**: Organize products with a flexible category system
- **Order Tracking**: Monitor and process customer orders with status updates
- **Customer Management**: View and manage customer information
- **Notifications System**: Stay informed about important events and activities
- **Messaging Center**: Communicate with customers and team members
- **Responsive Design**: Optimized for all devices from desktop to mobile
- **Dark/Light Mode**: User interface adapts to your preference
- **Real-Time Updates**: Instant data synchronization with React Query

## 🛠️ Tech Stack

- **Frontend Framework**: [Next.js 15](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State Management**: [React Query](https://tanstack.com/query)
- **Authentication**: [Supabase Auth](https://supabase.com/auth)
- **Database**: [Supabase](https://supabase.com/)
- **Form Handling**: [React Hook Form](https://react-hook-form.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Notifications**: [React Hot Toast](https://react-hot-toast.com/)
- **Date Formatting**: [date-fns](https://date-fns.org/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18.x or higher)
- npm or yarn
- Supabase account for database and authentication

### Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/electro-shop-admin.git
cd electro-shop-admin
```

2. Install dependencies

```bash
npm install
# or
yarn install
```

3. Set up environment variables
   Create a `.env.local` file with the following variables:

```
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
NEXT_PUBLIC_EXCHANGE_RATE_API_KEY=your_exchange_rate_api_key
```

4. Run the development server

```bash
npm run dev
# or
yarn dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser

### Deployment

The application is configured for easy deployment on Vercel:

```bash
npm run build
# or
yarn build
```
