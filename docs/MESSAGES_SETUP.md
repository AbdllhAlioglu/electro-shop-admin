# Mesajlar Modülü Kurulum Rehberi

Bu rehber, Electro Shop Admin panelindeki Mesajlar modülü için Supabase veritabanı kurulumunu açıklamaktadır.

## Veritabanı Tabloları

Mesajlar modülü için iki tablo oluşturulacaktır:

1. `messages` - Müşterilerden gelen mesajları saklar
2. `message_replies` - Mesajlara verilen yanıtları saklar

## Supabase SQL Editörü ile Kurulum

1. Supabase projenize giriş yapın
2. Sol menüden "SQL Editor" seçeneğine tıklayın
3. "New Query" butonuna tıklayın
4. Aşağıdaki SQL kodunu kopyalayıp yapıştırın:

```sql
-- Create messages table
CREATE TABLE IF NOT EXISTS messages (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  sender VARCHAR(255) NOT NULL,
  email VARCHAR(255),
  phone VARCHAR(50),
  subject VARCHAR(255) NOT NULL,
  content TEXT NOT NULL,
  date TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  isRead BOOLEAN DEFAULT FALSE
);

-- Create message_replies table for storing replies to messages
CREATE TABLE IF NOT EXISTS message_replies (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  message_id BIGINT REFERENCES messages(id) ON DELETE CASCADE,
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  created_by VARCHAR(255) NOT NULL
);

-- Add RLS (Row Level Security) policies
ALTER TABLE messages ENABLE ROW LEVEL SECURITY;
ALTER TABLE message_replies ENABLE ROW LEVEL SECURITY;

-- Create policy for authenticated users to read messages
CREATE POLICY "Authenticated users can read messages"
  ON messages
  FOR SELECT
  TO authenticated
  USING (true);

-- Create policy for authenticated users to update messages (mark as read)
CREATE POLICY "Authenticated users can update messages"
  ON messages
  FOR UPDATE
  TO authenticated
  USING (true);

-- Create policy for authenticated users to delete messages
CREATE POLICY "Authenticated users can delete messages"
  ON messages
  FOR DELETE
  TO authenticated
  USING (true);

-- Create policy for authenticated users to read message replies
CREATE POLICY "Authenticated users can read message replies"
  ON message_replies
  FOR SELECT
  TO authenticated
  USING (true);

-- Create policy for authenticated users to insert message replies
CREATE POLICY "Authenticated users can insert message replies"
  ON message_replies
  FOR INSERT
  TO authenticated
  WITH CHECK (true);

-- Create indexes for better performance
CREATE INDEX IF NOT EXISTS idx_messages_date ON messages(date);
CREATE INDEX IF NOT EXISTS idx_messages_isread ON messages(isRead);
CREATE INDEX IF NOT EXISTS idx_message_replies_message_id ON message_replies(message_id);

-- Create function to update message timestamp when marked as read
CREATE OR REPLACE FUNCTION update_message_read_timestamp()
RETURNS TRIGGER AS $$
BEGIN
  IF OLD.isRead = FALSE AND NEW.isRead = TRUE THEN
    NEW.date = NOW();
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- Create trigger to update timestamp when message is marked as read
CREATE TRIGGER update_message_read_timestamp_trigger
BEFORE UPDATE ON messages
FOR EACH ROW
EXECUTE FUNCTION update_message_read_timestamp();
```

5. "Run" butonuna tıklayarak SQL sorgusunu çalıştırın

## Satış Sitesi Entegrasyonu

Satış sitenizden mesajları admin paneline göndermek için aşağıdaki adımları izleyin:

1. Satış sitenizde bir iletişim formu oluşturun
2. Form gönderildiğinde, Supabase'e bir mesaj eklemek için aşağıdaki kodu kullanın:

```javascript
import { supabase } from "./supabaseClient";

async function submitContactForm(formData) {
  const { data, error } = await supabase.from("messages").insert([
    {
      sender: formData.name,
      email: formData.email,
      phone: formData.phone,
      subject: formData.subject,
      content: formData.message,
      isRead: false,
    },
  ]);

  if (error) {
    console.error("Error submitting form:", error);
    throw error;
  }

  return data;
}
```

## Mesaj Bildirimleri (Opsiyonel)

Yeni mesajlar için bildirim almak isterseniz, Supabase'in Realtime özelliğini kullanabilirsiniz:

```javascript
// Admin panelinde
const messagesSubscription = supabase
  .from("messages")
  .on("INSERT", (payload) => {
    // Yeni mesaj bildirimi göster
    showNotification({
      title: "Yeni Mesaj",
      message: `${payload.new.sender} tarafından yeni bir mesaj alındı`,
      type: "info",
    });
  })
  .subscribe();

// Aboneliği temizleme
return () => {
  supabase.removeSubscription(messagesSubscription);
};
```
